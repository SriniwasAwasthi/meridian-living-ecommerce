# Contributing Guidelines

Thank you for your interest in contributing to **Meridian Living E-Commerce**!

## 🚀 Development Workflow

1. **Clone the Repository**
   ```bash
   git clone https://github.com/SriniwasAwasthi/meridian-living-ecommerce.git
   cd meridian-living-ecommerce
   npm install
   ```

2. **Configure Environment**
   - Copy `.env.example` to `.env` and set your PostgreSQL connection string.

3. **Run Dev & Tests**
   ```bash
   npm run dev
   npm test
   ```

4. **Submit a Pull Request**
   - Use conventional commit messages (`feat:`, `fix:`, `docs:`, `test:`).
   - Ensure all automated tests pass.
